Help & Keyboard Shortcuts

Getting Started

Hephestus is a supervised research command agent. Commands run with your account permissions; policy checks are not a sandbox. Enter a goal, and the agent will plan and propose commands to achieve it. All commands require your explicit approval before execution.

Keyboard Shortcuts

  • Ctrl + Enter - Start a new task
  • Escape - Close modals / Cancel approval
  • A - Approve all commands (when approval panel is open)
  • R - Reject all commands (when approval panel is open)

Safety Features

  • All commands must be approved before execution
  • Dangerous commands are blocked by policy
  • Kill switch: Create a file named HEPHESTUS_STOP to halt immediately
  • Maximum steps limit prevents runaway execution

Local Model

Hephestus runs the configured GGUF model locally with llama.cpp. Ensure the model file exists and that llama-cpp-python is installed; CUDA-enabled builds use available GPU memory for acceleration.
